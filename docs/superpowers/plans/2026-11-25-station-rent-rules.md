# 案場租金規則與租約佐證分離實作計畫

**目標：** 案場可查電號、跨期租金規則及租約附件狀態；新單據配對後依已確認規則產出租金預覽，缺租約附件不等於不能計算。

**架構：** 租金規則獨立版本化資料表關聯既有案場，保留資料來源、適用期間、週期與佐證狀態。預覽從現有單據彙整，沿用金額計算器；歷史人工驗算資料保留，不能冒充新一期自動結果。

**技術：** Rust / PostgreSQL / React；本地 Docker 驗證。固定 marrash 分支，不部署客戶端。

- [x] 建規則表及讀寫 API，權限、版本與來源檢查，租約附件獨立。
- [x] 新單據預覽按案場／適用規則／付款週期彙整；缺單、零元、重複、跨期明確處理。
- [x] 案場畫面顯示／管理規則與佐證；既有租金預覽顯示自動來源與待確認原因。
- [x] 讀現有資產總表與已驗案例，確認部分匯入，其餘保存待確認；不將簽約日冒充生效日。
- [x] 本地驗證既有麻豆案例與合成下一期兩張單據、缺一張、重複、未確認規則、附件未齊。
- [x] 獨立檢查結果、交付說明與限制；不將本地試算視為正式付款或客戶驗收。

來源附件與真實案場資料只存私有 output，不進 Git。自動計算規則不得靠案場名稱猜測，不以總應付金額取代售電收入，不以缺單當零。
