# 電費主表優先的租金資料核對

1. 以電費單超強表格「自動化所需欄位」的電號、案場、公司作為主對照，逐筆核對原32項；保留來源雜湊與列號。
2. 連接資產、地主與付款分頁。專案編號不能單獨決定地主對應；名稱／對象不符時不得跨案套用。
3. 補入已有證據的固定額、姓名、年度基底及共用金額；既有核對不足的月付款不逆推成固定規則。
4. 平台顯示共用整組金額但不複製個別付款；年額已知而分期未知時不得假設均分。
5. 備份本地資料庫，以既有規則 ID／版本更新32項，不重建、不修改歷史付款、不部署客戶遠端。
6. 更新核心大表與逐項缺口，驗證金額、錯配移除、主電號未變及重跑不新增資料。固定使用 marrash 分支。
