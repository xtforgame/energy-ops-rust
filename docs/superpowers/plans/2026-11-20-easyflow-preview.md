# 電費單至 EasyFlow 可讀表單（已獲使用者同意實作）

目標：本機上傳真實 PDF，依電號查案場主檔，預覽 EasyFlow 應填內容。無須地主租約，不代送 EasyFlow。

1. 主檔匯入支援超強表格「自動化所需欄位」分頁；保留既有發電案場清單匯入。
2. 草稿 API 支援先收單後匯主檔，以帳單日期及電號重新查詢；保持唯讀、組織隔離。
3. 依已提供對照圖，呈現公司、案場、對象、未稅開票額或付款明細、日期、附件。未確認選項不沿用範例人員。
4. 申請摘要可從案場名稱產生；原單淨額與未稅開票額明確分開。
5. 以合成測試驗證核心規則，再於本機匯入客戶主檔與 PDF 實測。原檔不進 Git。
6. 更新 localhost:11950，檢查瀏覽器表單。客戶遠端不動。
