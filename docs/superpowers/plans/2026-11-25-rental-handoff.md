# 電費與租金可審核交付補強

目標：以麻豆原始完整 PDF 經平台收件產出電費及租金表單，保留真實缺件；不部署遠端、不送出 EF。

1. 原始 PDF：識別各頁來源，分開產生電費單，保留原附件頁碼；避免租金封面重複入帳。驗證原始九頁 PDF。
2. 租金規則：已知固定、面積、比例、保底規則可以正式確認及計算；未知級距參數精確列缺，不擅定。費用說明完整列基底、比例、進位、稅與期限。
3. 租金案件：以案場、規則、週期建立唯一保存案件；保存 EF 欄位、憑證安排與來源版本；同組任一人可確認，資料異動須重新確認。確認不等於 EF 已送出。
4. 表單：可編輯保存完整付款申請欄位、下載人可閱讀 HTML，顯示真實缺項。
5. 附件：提供 ZIP，包含表單、計算、實際可取得的單據與租約／憑證，附缺件清單；授權檢查及安全檔名。
6. 驗證：單元測試、前端 build、Rust build、local API 原 PDF 輸入驗算、UI 下載兩類表單。麻豆預期租金 12,982，來源與輸出逐項比對。另測版本衝突、重複收件與空缺資料。
7. 交付：兩份表單及附件包、驗證結果；明確區分已通過與 EF、真實環境尚未驗證。
