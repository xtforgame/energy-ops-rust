# 逆變器電費明細對帳修正（2026-11-22）

## 原因
兩份既有 PDF 的辨識原始結果已包含基本電費、流動電費、功率因數調整費、電子帳單優惠及電價調整。平台漏接電子帳單優惠與稅前總額，而且 EasyFlow 草稿只用電表租費、設備使用費對總額，造成明細不平。

## 修正
- 補上 meterReadingDiscount 與 taxBeforeAmount 的後端／前端對應。
- 高壓繳費通知單保留各計費項目的正負號，明細加總按整元核對；另以稅前金額加營業稅核對總額，避免重複加稅。
- 舊單據可從已保存的原始辨識結果補讀新欄位；不覆蓋人工明確清空或修正的值。
- 預覽、HTML 與 CSV 匯出呈現明細對帳及整元差額。
- 不需資料庫 schema migration，不變更 OCR 模型。

## 已驗證
- 兩張既有逆變器 PDF 在隔離本地平台重新上傳並實際辨識，皆正確對應案場並可預覽付款申請。
- 僅設備使用費樣本：1285.7 + 3720 - 45.8 - 10 + 85 = 5034.9，整元 5035；4795 + 240 = 5035。
- 含租費樣本：514.2 + 2711.2 - 49.2 - 10 + 1549 + 54.8 = 4770；4543 + 227 = 4770。
- 兩張瀏覽器預覽與可閱讀 HTML 下載驗證通過，無 page errors。
- 六筆既有樣本的案場、金額、申請類型回歸檢查通過。
- Rust domain／extractor 35 項測試、EasyFlow draft 後端整合測試、前端 5 項測試及前端建置通過。

## 範圍
只驗證既有樣本與本地平台，未部署客戶端、未送出 EasyFlow。申請表內容變動會讓已確認草稿要求重新確認；這是既有防止過期審核的機制。對帳相符不等同正式簽核通過。
