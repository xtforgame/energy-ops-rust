# 規格文件系統（docs/spec）

「電費單與租金管理系統」的規格文件。以雲豹委託開發合約附件一的驗收表（表一 B01～B15、表二 R01～R08）為基準，
盤點三個來源（原版設計文件、App 5、energy-ops-rust）的規格與實作，標出每個部分的實作狀態、釐清狀態與資料可信度，
並把不清楚的地方整理成分批的待釐清問題。

目前版本：v0.1 盤點版（2026-11-12）。

2026-11-17 已與線上規格書網站（正本在網站資料庫）同步：線上 14 筆修改（Marrash 2026-11-16 補登進度、Q-04 審核規則）已套回 `src/`，整份線上內容另存在 `online/spec-online-<日期>.json`（規格項目、修改紀錄、討論、資料測試、附件清單；附件檔本身不在裡面）。之後以線上為準，要改規格請在網站或規格書 MCP 上改，再同步回來。

## 怎麼改

HTML 與 SVG 都是產生出來的，不要直接改。改內容時：

1. 清冊資料（驗收項、需求、問題、現況、假資料、決策、比對紀錄、來源、名詞）改 `src/registers.mjs`。
2. 敘述文字（首頁、摘要、各架構圖的導讀）改 `src/pages.mjs`。
3. 架構圖的方塊、狀態、標籤、連線改 `tools/diagrams.mjs`；狀態的顏色與樣式只定義在 `tools/lib.mjs`。
4. 重新產生：

```sh
node docs/spec/tools/build.mjs
```

會重畫 `diagrams/*.svg`、重寫所有頁面與 `dist/` 的單檔版。Node 18 以上即可，沒有外部相依。

要 PDF 時再跑 `node docs/spec/tools/pdf.mjs [輸出路徑]`。

## 狀態代碼

| 欄位 | 代碼 | 顯示 |
|---|---|---|
| 實作（impl） | `done`／`partial`／`todo`／`beyond`／`external`／`dropped` | 已具備／部分具備／未實作／合約外既有／外部系統／不採用、範圍外 |
| 釐清（clar） | `confirmed`／`assumed`／`open` | 已確認／預設、假設／待釐清 |
| 資料（data） | `mock`／`uncertain` | 假資料／資料不確定 |

實作狀態以 energy-ops-rust 為準，對照的是合約與需求要的樣子。判定原則見「圖例與編號規則」。

## 機敏資料

使用者提供的原始檔案（合約、SOP、資產管理清單、租金計算、發電案場清單、範例電費單）不放進版控。
本文件只引用檔名、雜湊與結構，不轉載密碼、帳號、銀行資料、個人聯絡方式與合約金額。
