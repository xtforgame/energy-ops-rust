規格來源與世代

規格散在三個 repo、四個世代與一批使用者提供的檔案裡。這一頁說明每個來源是什麼、衝突時以誰為準，以及本次抓取與比對的結果。

衝突時以誰為準

  1. 合約正式簽署版（含附件一表一、表二）——目前拿到的是「修改附件驗收項目」版，正式版待核（Q-01）。
  2. 雙方簽認的驗收測試清單——尚未建立（Q-03）。
  3. 需求總表 v0.1（2026-11-08）——機器轉錄整理，明註「不代表已簽核規格」。
  4. 現行作業：SOP、電費單超強表格、資產管理清單、租金計算範例——反映實務，但範例有錯。
  5. 原版設計文件（RT）與 App 5 文件——內部設計，許多決定是設計者代決。
  6. 程式現況（energy-ops-rust）——只說明「做了什麼」，不代表「應該做什麼」。
