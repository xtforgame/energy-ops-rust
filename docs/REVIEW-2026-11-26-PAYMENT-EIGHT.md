# 2026-11-26 電費付款八項格式驗證

## 修改
- 電費付款最上方依序顯示公司、有無合約、摘要、付款對象、付款方式、付款條件、憑證單據、分項事由/幣別/金額；開票單保留獨立格式。
- API 新增 paymentLineItems，CSV 也包含 EF申請分項。原有 lineItems 保留原單數字與正負號供驗算。
- 高壓逆變器單在原始明細及稅額對平後，彙整為逆變器使用電費、電表租費與存在的遲付費用；不對平不推算。整元差異列入使用費並保留原單驗算說明。
- 付款方式採明示付款說明、代繳帳號或已確認付款條碼；缺資料不把未知當作無條碼。

- 原單服務單位支援分處、服務所；未擅自替換成未確認的上層區處。
- OCR modernRenewableBillParser 保留原單匯款說明；另修正既有測試 optional-array 存取型別錯誤。
