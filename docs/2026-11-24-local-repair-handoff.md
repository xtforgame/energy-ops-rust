# 本地上線修正交接（2026-11-24）

本次只更新本地隔離測試環境，未推送 Git、未部署客戶端、未實送 EasyFlow。不能將下列通過項目解讀為整個系統已完成正式驗收。

## 已修正

1. 一般候選審核人員按通過時先取得任務，保留組外拒絕與重複動作防護。
2. 附件簽名使用可由使用者瀏覽器連線的 EO_S3_PUBLIC_ENDPOINT；服務內部儲存連線不變。
3. 交接確認新增必要欄位／日期及來源附件檢查。資料未齊仍可儲存與匯出草稿，但不能標記為已確認。
4. 租金憑證安排可持久化、檢查版本並留下異動紀錄；尚未代表發票實際到件。
5. 三種購電公司單據的買方名稱／統編直接取原單，不錯套案場原本台電開票對象。
6. 大型 PDF 改逐頁處理；租金年度計算表採首頁明細並使用既有確認規則重算，不宣稱後附單據已全部核對。
7. 收信資料夾工具認得租金計算表終態，保留去重與回應不明的人工核對保護。
8. 新增電費紀錄 CSV，前段沿用既有表格欄序；無依據的收件／送件／付款日期不填造。
9. 租金週期輸出改為可閱讀 HTML，標示缺件與非正式付款狀態。
10. 新增隔離備份與還原測試腳本；不動其他 Docker 專案。
11. 接受邀請使用與建立邀請相同的應用時鐘。

12. 電費審核可選台電或天能組，組內任一人通過；未知轉供承辦組別不猜測。租金維持獨立作業。已啟動流程不可更換組別。
13. 轉供單據去重身分加入來源版型，避免同電號同期間被台電單擋掉；migration 0109 更新既有轉供鍵。

## 環境／交付注意

- Rust 與 web 同版建置；OCR 是獨立專案，必須一併更新。本地另有 OCR source patch ZIP，不在本 repo 內。
- 需保留資料庫、MinIO 物件、Compose／設定／秘密、實際部署程式與 OCR 模型版本。備份腳本不收秘密設定，應另外受控保存。
- 本地 bind mount 的程式不等於映像已更新。此版本尚未重打完整離線安裝包。
- 原單、資料庫與私人憑證不得提交 Git。
