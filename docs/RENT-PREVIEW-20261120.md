# 本地租金付款預覽驗證

## 已實作
- 單據頁並列 EasyFlow 申請與地主租金預覽。
- GET/POST `/api/v1/orgs/{org}/energy/bills/{billId}/rent-payment`：管理員匯入核對來源，保存於案場 data.rentPaymentDrafts，GET 由 Decimal 引擎重新計算，不儲存預期答案作計算結果。
- 指定實際計算起迄、台電與轉供期間齊備檢查、重複來源／期間重疊阻擋、逐筆或總額取整數、外加稅及來源附件頁碼。
- 組織權限、來源附件組織範圍、交易與稽核事件 station.rent_sources_updated。
- 可下載 HTML 付款預覽，不建立付款、不提交 EasyFlow、不改審核狀態。

## 實跑
測試組織 2；麻豆單據 4、蘇澳單據 6。獨立台電頁上傳走原 OCR；租金來源經人工核對與 Excel 匯入，並非整包 OCR 自動彙整。
- 麻豆：含稅收入 5481、149069，各筆乘8%取整後12364；外加稅618，總額12982。
- 蘇澳：原PDF第6/7/8頁三期收入393631、241015、290220，合計924866；依客戶試算未稅基底乘8%取整73989，稅3699，總額77688。
- 實際 API、UI、下載文件對帳通過；18項領域測試通過；前端production build通過。
- 未登入、跨組織、無效來源附件拒絕，無效寫入不影響既存數據；另一案場不顯示這兩案租金。

## 邊界與未完成
- 收件整包PDF跨頁混值與自動分拆尚未修正。本次來源是人工核對資料匯入，介面與下載均明示。
- 蘇澳主檔及函文採未稅基底，與先前合約截圖的含稅文字差異待確認；每月最低8000元的跨月分攤未套用，本次按客戶本期函文驗算，不宣稱通用租約引擎已驗收。
- 蘇澳獨立台電頁OCR未稅收入正確，但稅額抓成電表租費稅額13，並缺電費合計；此問題未修。租金採已核對Excel收入，未使用該錯誤稅額。
- 目前仍無正式地主合約與簽核工作流建檔，故單據主頁有缺合約警示；本次完成預覽，不解除送審條件。
- 可計算資料是管理員API匯入；尚無來源與規則編輯UI、全自動Excel主檔同步及信箱自動串接。
- 客戶資料不進Git；只部署本地11950，未更新遠端，未推送。
