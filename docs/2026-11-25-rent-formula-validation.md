# 租金公式可用性與本地驗證

## 本次行為

- 租金公式可否試算、正式規則確認、租約附件齊備分開顯示。
- 比例、固定、面積、保底、年度基準各自保留已知參數；未知進位顯示原值，未知稅務保留租金基數。

- 更新工具以來源鍵、電號、版本及指紋核對既有規則；本地附件 ID 不可直接跨環境套用。
