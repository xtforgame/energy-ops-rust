# 電費資料審核與地主租金分離（2026-11-23）

## 行為
- 電費單：上傳／辨識 → 電號對案場 → EasyFlow 申請預覽 → 電費審核群組任一人確認。
- 地主租金：依租約、計算規則及付款週期另行計算。缺租約或租金策略不阻擋電費資料審核。
- 新電費送審使用組織共用 `bill-data-review`，不要求逐電號綁定，也不啟動舊流程中的 `rating.computePayout`。
- 收件台與電費單頁兩個送審入口使用相同規則。舊電費單的 pendingContract 狀態亦可送審；新辨識資料有案場即進 pendingReview。
- 審核仍檢查來源附件、電號、計費起迄及總額。繳費期限不適用每種電費單，不作共通必填。
- 同一承辦可送審並確認，但必須屬於電費審核群組；群組外人員不能認領。空群組不會自動通過。
- 已通過／正在審核的單據不得重複送審，保留原有跨單據重複檢查。

## 部署
一般更新程式即可，不需 schema migration。首次電費送審會建立共用審核定義（交易鎖避免並行重複建立），並確保審核群組存在；管理員須設定正式審核成員，不會自動授權所有人。
既有已啟動流程保留原版本與歷史，不自動搬移或改寫；此變更適用新送審。若有卡在舊流程的在途單據，先盤點再依正式權限處理，不直接篡改其核准狀態。
